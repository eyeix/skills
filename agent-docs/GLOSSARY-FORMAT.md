# 术语表格式

`glossary.md` 只放术语定义,不放实现细节。首次需要记录术语时创建该文件。

## 文件结构

```markdown
# 术语表

<一到两句:本项目是什么,为什么存在>

## 语言

**<术语>**:
<一到两句定义。定义描述概念是什么,不描述它做什么>
_避免_: <同义词列表>

## 关系

<术语间存在包含、组合、状态流转关系时,用一到两句集中描述>
```

`_避免_` 行可省略:该词无同义词竞争时省略。`## 关系` 一节可省略。

## 规则

- **果断取舍**:同一概念有多个候选词时,选定最好的一个,其余列入 `_避免_`;
- **定义收紧**:一到两句为限,超限说明定义的是实现而非概念;
- **只收项目特有概念**:通用工程概念(超时、错误类型、工具函数模式)不收,即使项目大量使用;
- **自然分组**:术语形成明显聚类时用子标题分组,单一领域的扁平列表即可。
