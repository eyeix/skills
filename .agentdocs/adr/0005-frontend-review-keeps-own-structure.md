# 前端审查 skill 保持独立形态,不做仓库风格同化

`review-frontend-production` 以完整规则库(9 份审查参考与台账协议)、Python 标准库脚本与回归测试构成,规则与台账结构保持原样;frontmatter、标点与展示名适配仓库约定,但不按其余 skill 的风格逐句重构。

## 背景

该 skill 体量大(约 4700 行审查规则 + 台账脚本 + 回归测试),价值恰在规则的完备与台账结构的精确;逐句重构会引入偏差,且等价性难以逐项验证。

## 备选方案

- 逐句重构统一为仓库风格:被否决,规则密度下重构成本与失真风险超过一致性收益;
- 只保留 Markdown、不写脚本与测试:被否决,台账机械校验是完整性门槛的核心,SKILL.md 的命令会全部失效。

## 后果

- 该 skill 的规则演进整批评估,不零散改写;规则与台账结构整体保持稳定;
- 仓库 AGENTS.md 的检查范围从"纯 Markdown 与少量 Node 脚本"扩展到含 Python 标准库与 unittest;
- 该 skill 保留英文术语缩写(PAGE/CMP/FND/CHK 等)与独立的文件布局,风格差异由此 ADR 交代。
