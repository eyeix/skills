# 术语表与决策记录替代"全局重要记忆",全部懒创建

`.agentdocs/` 的知识沉淀分三条轨道:术语进 `glossary.md`,难逆转决策进 `adr/`,可复用模式与跨文件约束进领域文档。不再设"全局重要记忆"章节。`glossary.md` 与 `adr/` 在首次有内容可写时才创建,初始化时不预先铺设。

## 背景

原索引文档设"全局重要记忆"章节,与各领域文档中的"记忆"段落、跨项目记忆工具 engram 三处重叠,边界模糊导致同一知识写哪都行、哪都不写。预先铺设目录结构则产生空文件与双写维护成本。

## 决策

三轨分立、按内容性质分流,以懒创建消除空文件:术语(概念边界)、决策(为什么这样做)、约束(怎么做事)各有唯一去处。跨项目记忆(用户偏好、机器差异)明确归 engram,不进 `.agentdocs/`。

## 后果

- 索引不再承载记忆内容,只列领域文档与任务条目,索引维护成本降到最低;
- 决策记录设三条门槛(难逆转、无上下文会困惑、真实权衡),门槛不满足的决策不记录;
- 与 mattpocock/skills 的 GLOSSARY/ADR 模式同构,但其根目录布局改为 `.agentdocs/` 集中布局。
