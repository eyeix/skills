# 记忆审查

数据目录：`${ENGRAM_MEMORY_DIR:-$HOME/.engram}`（下称 `$GM`）。
初始化无需手动执行：目录结构、记忆模板、git 仓库由首次 Stop 巩固自动创建。

## 审查流程

1. 读取 `$GM/MEMORY.md`、`$GM/USER.md` 与 `$GM/archive/` 中最近的归档文件；
2. 逐条评估：是否过时、重复、与用户最新指令矛盾；
3. 给出整理方案（保留/合并/改写/淘汰），征得用户确认后执行；
4. 淘汰内容移入 `$GM/archive/YYYY-MM-DD.md` 并注明日期；
5. 检查两个文件是否超出字符上限（3000/1500），超限时提出浓缩方案；
6. 若 `$GM` 为 git 仓库，整理完成后提交一次（提交信息形如 `chore: 记忆整理`）。
