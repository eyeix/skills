# 学习记录格式

学习记录存 `./learning-records/`,顺序编号:`0001-slug.md`、`0002-slug.md`。首次写记录时懒创建目录。

它们是教学版的决策记录:记下非显然的教训、关键洞见、用户声明的既有知识——它们将操纵未来的会话。用于计算最近发展区。

## 模板

```md
# {学到或确立了什么的短标题}

{1–3 句:学到了什么(或确立了什么既有知识),以及它为何影响未来的会话。}
```

格式到此为止。学习记录可以是单段。价值在于记录"这已经知道了"与"它为何改变接下来教什么",不在于填满章节。

## 可选章节

只在真正增加信息时包含,多数记录不需要:

- **Status** frontmatter(`active | superseded by LR-NNNN`):早先的理解被证明有误并被替换时;
- **证据**:用户如何展示了理解(答对的问题、完成的练习、引用的既有经验)。论断可能被重访时有用;
- **影响**:这为未来会话解锁或排除了什么。不显然时值得记。

## 编号

扫描 `./learning-records/` 取最大编号,加一。

## 何时写学习记录

任一为真就写:

1. **用户展示了非平凡的真实理解**:不止接触,而是能正确使用该概念的证据。这为接下来教什么立了新的下限;
2. **用户披露既有知识**:"我已经会 X。"记下来,未来的会话不再重教;一并记录声称的深度;
3. **一个误解被纠正**:用户先前相信了错的,现在明白为什么。这类价值最高:它们预测相关主题的未来绊脚石;
4. **使命因学习而偏移**:用户发现自己在意的与原以为的不同。交叉链接 `MISSION.md` 并更新它。
